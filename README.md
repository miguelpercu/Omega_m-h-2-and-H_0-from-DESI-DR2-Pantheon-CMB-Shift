# Omega_m-h-2-and-H_0-from-DESI-DR2-Pantheon-CMB-Shift
A reproducible MCMC analysis of cosmological parameters (H_0, Omega_m h^2) using DESI DR2 baryon acoustic oscillation measurements, Pantheon+ Type Ia supernovae with full covariance, and CMB shift parameters. We measure H_0 = 69.91 +/- 0.71 km/s/Mpc and Omega_m h^2 = 0.14763 +/- 0.00126, with a 3.6 sigma deviation from Planck 2018
